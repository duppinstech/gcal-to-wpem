# Security policy

## Supported versions

We aim to address security issues affecting the **latest release** on the default branch. Older versions may receive fixes at our discretion.

## Reporting a vulnerability

**Please do not** open a public GitHub issue for undisclosed security vulnerabilities.

Instead:

1. Use [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/about-github-security-advisories) for this repository (**Security** tab → **Report a vulnerability**), if enabled for the repo, **or**
2. Email the repository maintainer privately with:
   - A clear description of the issue
   - Steps to reproduce (proof-of-concept if applicable)
   - Affected version(s) and component(s), if known

We will acknowledge receipt as soon as we can and work on a fix and coordinated disclosure timeline.

## Scope

In scope: this plugin’s PHP code and bundled behavior when used with supported WordPress and WP Event Manager versions.

Out of scope: third-party hosts, misconfigured servers, leaked credentials, or issues in WordPress core or other plugins unless directly caused by this plugin’s code.

## Safe harbor

We appreciate responsible disclosure and will not take legal action against researchers who follow this policy and act in good faith.
